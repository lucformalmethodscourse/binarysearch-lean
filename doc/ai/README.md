# AI transcripts

Condensed records of AI-assisted sessions on this project.

Conventions:
- File name: `YYYY-MM-DD-<topic>.md` (date of the session start), so files sort chronologically.
- Header: session start date/time with UTC offset.
- Each user prompt is stamped with its time (`HH:MM`, local) and quoted verbatim; assistant responses are condensed.
- Links to project files are relative to the transcript.
